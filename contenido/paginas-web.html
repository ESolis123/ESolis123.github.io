Consultorio Odontológico

Proyecto desarrollado para la materia de Proyecto Integrador en la universidad. Consiste en una plataforma de gestión integral para consultorios odontológicos con soporte multiusuario (doctores, asistentes y administradores del sistema).

Características principales:

  • Gestión y calendario de citas
  • Odontograma interactivo
  • Control de facturación y pagos
  • Generación de reportes
  • Módulo de sugerencias impulsado por Inteligencia Artificial
  • Administración de perfiles para doctores y asistentes

Página para cotizaciones

Aplicación web diseñada para la generación automatizada de cotizaciones de productos orientada al mercado dominicano. Permite agilizar el proceso comercial mediante la consulta de clientes a través del buscador de RNC, la administración centralizada de proveedores, clientes y catálogo de productos, el manejo flexible de precios y la exportación directa de cotizaciones en formatos Excel o PDF sin intervención manual.

Características principales:

  • Consulta y selección rápida de clientes mediante buscador de RNC (mercado dominicano)
  • Gestión integral de proveedores y clientes
  • Administración de catálogo de productos y control de precios
  • Generación automática de archivos Excel y PDF para las cotizaciones
  • Optimización del flujo de ventas y eliminación de procesos manuales
